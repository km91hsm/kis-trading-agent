> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 새 웹 UI(M11b)가 쓰는 `/api/` 12 자원·SSE·nav 생성 파일·텔레그램 인라인 버튼·알림 피드·조작 이력을 백엔드에 만들고, 옛 `tests/web/*` API 테스트를 자원 경로로 이식한다. 프런트는 건드리지 않는다.

**Architecture:** 커널 `kernel/web` 셸이 Host/tailnet 게이트·시각 헤더·SSE·같은 경로 부분 응답 합치기(`merge.py`)·`jobs`/`system` 자원을 제공하고, 각 기능은 `feature.py` 의 `routes`/`resources`/`sse_keys`/`nav`/`telegram_callbacks` 로만 등록한다. 웹 프로세스(`trader web`)는 원장만 읽고 쓰며 집행은 데몬 큐(`approve_execute`)가 한다. 신설 `features/quotes` 가 실시간 시세 허브(KIS 웹소켓 임차)·환율·차트·종목명을 맡는다.

**Tech Stack:** Python 3.12, FastAPI + Starlette TestClient, SQLite 원장(마이그레이션 15), `websockets`(spot notice 가 이미 의존), httpx(텔레그램), pydantic v2, pytest.

**Spec:** `docs/superpowers/specs/2026-11-04-m11-web-ui-design.md`(이 플랜의 1차 근거, §3·§5.1·§7·§8·§13) + 상위 `docs/superpowers/specs/2026-11-02-kis-trading-agent-replatform-design.md` §2.3·§2.5·§3 M11. 옛 구현(이식 원본, 읽기 전용): `/Users/ohhyeonseok/LLM/trading-agent/src/trader/web/`·`tests/web/`. 옛 저장소의 `config/`·`secrets/`·`state/` 는 열지 않는다.
