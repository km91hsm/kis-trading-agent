# M1 — kernel/broker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 옛 저장소 `src/trader/broker/`(KIS auth·client·market·broker·ws 프레임·fake·tr_ids·`_parse`·교차 프로세스 레이트리미터·선물옵션 브로커)를 **동작 보존**으로 `src/trader/kernel/broker/` 에 옮기고, 옛 `tests/broker/*` 17 파일(약 160 테스트)을 `tests/kernel/broker/` 로 이식해 통과시킨다. 완료 기준 "`kis ping` 코드 경로 테스트 통과" 는 `broker.ping.run_checks` 함수 테스트로 충족한다(CLI 명령은 계좌·시크릿이 생기는 M2 에서 등록).

**Architecture:** 세 겹 구조(`KisAuth(env)` → `KisClient(env, auth)` → `KisMarket(client)` 실전만 / `KisBroker(account, client)` env 일치)를 그대로 둔다. 옛 코드가 `trader.config` 에서 가져오던 `AccountConfig`·`FoProductCfg`·`KisCreds`·`key_fingerprint` 는 커널에 yaml 로더가 없으므로 **DTO 로 `kernel/broker/` 안에 둔다**(`BrokerAccount`, `FoProduct`, `KisCreds`). M2 `features/accounts` 가 yaml → DTO 변환을 맡는다. 호가단위(`risk/ticks`)는 브로커가 전송 직전 검증에 쓰므로 `kernel/broker/ticks.py` 로 올린다(M4 의 risk 가 여기서 가져다 쓴다). 토큰 캐시·레이트 DB 위치는 `TRADER_KIS_SHARED_DIR` 가 있으면 그곳, 없으면 `state/`(스펙 §2.7-1).

**Tech Stack:** Python 3.12, httpx, pydantic v2(`extra="forbid"`), sqlite3(WAL), respx(테스트). 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-11-02-kis-trading-agent-replatform-design.md` §2.1(`kernel/broker` 행)·§2.7-1(리허설 날 자원 분리 `TRADER_KIS_SHARED_DIR`)·§3 M1. 옛 규칙 원문은 `../trading-agent/docs/architecture.md` 의 「브로커 주문」「시세·수급은 실전 env 클라이언트만, 주문·잔고는 계좌의 env」「KIS 실패는 전부 `KisApiError(msg_cd, msg1, tr_id)`」「계좌별 키·연결 키 입력」「국내 실시간 시세 웹소켓」.

## Global Constraints

- 옛 저장소는 `../trading-agent`(이 저장소와 같은 부모 디렉터리). 플랜의 `../trading-agent/...` 는 그 기준이다. 옛 `secrets/`·`config/`·`state/` 는 읽지 않는다.
- **동작 보존.** 매매·리스크 의미 변경 없음. 옛 테스트의 단언을 바꾸지 않는다(import 경로·fixture 이름·DTO 생성자만 바꾼다). 옛 코드의 알려진 불일치는 고치지 않고 `docs/architecture.md` 「broker」 절 "알려진 차이" 에 적는다.
- import 3층: 커널은 `trader.features` 를 import 하지 않는다(`registry.import_violations` 가 막는다). 커널 모듈끼리는 자유.
- 경로는 `platform.paths` 로만(`state_dir()`), 시각 ZoneInfo 는 `config.time` 한 곳(`KST`, 이번에 `ET`·`MARKET_TZ` 추가). 로거 이름 `trader.broker`. 사용자 대면 메시지·docstring 한국어.
- pydantic 모델은 `extra="forbid"`, 금액은 `Decimal`, 저장 시각 UTC ISO8601. subprocess 없음.
- 테스트는 `tmp_path`·`project` fixture 만 쓰고 네트워크는 respx 로 막는다. fixture JSON 은 옛 `tests/broker/fixtures/` 의 **합성 응답**만 복사하되 계좌번호 자리표시자(`00000000`)·가짜 키만 들어 있는지 복사 전에 확인한다.
- 레이트 한도 `RATE_PER_SEC = {"real": 20, "paper": 2}`, EGW00201 재시도 0.5·1.0·2.0초 최대 3회, 토큰 갱신 여유 1시간·실패 후 60초 재발급 금지·접속키 20시간 — 옛 값 그대로.
- 토큰 캐시 파일 `kis_token_<name>.json`, 레이트 DB `kis_rate.db`, 휴장일 캐시 `cache/holiday_YYYYMM.json` 이름 유지(옛 `state/` 와 공유 가능해야 리허설 날 두 데몬이 한도를 합산한다).
- 마일스톤 브랜치 `feat/m1-broker`, PR 대상 main, 커밋 트레일러 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. ruff line-length 100. CI ubuntu+windows 녹색.
- 커밋 작성자는 저장소 `git config user.email`(GitHub noreply) 그대로. 개인 이메일 금지.
