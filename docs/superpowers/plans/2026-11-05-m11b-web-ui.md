> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** M11 백엔드(12 자원·83 엔드포인트·SSE·nav 생성 파일) 위에 스펙 §6 의 다섯 화면 + 결정 상세를 React 로 구현해 휴대폰(390px)·PC 에서 쓰이는 PWA 를 만든다.

**Architecture:** `web/` 단일 Vite 앱. 상태 라이브러리 없이 `fetch` 캐시 + SSE 키 무효화(`lib/sse.ts` 리더 탭 1개)로 화면을 갱신하고, 시세는 `lib/live.ts` 가 서버의 `next_poll_ms` 로 폴링한다. 메뉴·SSE 키는 생성 파일(`generated/nav.ts`·`sse-keys.ts`)만 읽는다. 디자인은 첫 Task 에서 `ui-ux-pro-max` 로 토큰(`styles/tokens.css` + `web/DESIGN.md`)을 고정하고 이후 화면은 그 부품(`components/`)만 조합한다. 옛 저장소 `trading-agent/web/src` 의 **순수 함수**(api·events·live·clock·format·glossary·usage·trace·theme)는 테스트와 함께 이식하고 화면은 전부 새로 그린다.

**Tech Stack:** React 19 + Vite 7 + TypeScript 5.9 + vitest(jsdom) · `react-router-dom` 7 · `lightweight-charts` 5 · `pretendard` · 손으로 쓴 CSS 변수. 렌더 테스트는 `react-dom/client` + `act`(jsdom)로만 한다(테스팅 라이브러리 없음).

**Spec:** `docs/superpowers/specs/2026-11-04-m11-web-ui-design.md` §3·§5·§6·§9·§10 (+ 상위 스펙 §2.5). 목업: `docs/superpowers/specs/assets/m11-mockups/all-pages-v3-desktop.html`(승인된 v3, PC 9 구간)·`today-accounts-mobile.html`(휴대폰). 백엔드 응답 모양의 출처는 각 기능 README 「웹」절과 라우터 docstring(`src/trader/features/*/routes.py`, `src/trader/kernel/web/routers/*.py`)이다.

## Global Constraints

- 의존성: `react`·`react-dom`·`react-router-dom`·`lightweight-charts`·`pretendard` 외 **런타임 의존성 추가 금지**(스펙 §3). dev 의존성도 현재 목록(`vite`·`vitest`·`jsdom`·`typescript`·`@vitejs/plugin-react`·`@types/*`) 외 추가 금지. 아이콘은 인라인 SVG(라이브러리 금지).
- 생성 파일 `web/src/generated/sse-keys.ts`·`nav.ts` 는 손으로 고치지 않는다(`uv run trader dev gen-sse-keys|gen-nav`). 메뉴 항목·SSE 키는 이 두 파일에서만 온다.
- 엔드포인트는 M11 이 고정한 83개(`tests/kernel/web/test_endpoint_map.py`)만 부른다. **백엔드 변경 금지**(응답 모양이 모자라면 화면이 계산하거나 숨기고, 플랜 끝 「백엔드 요청」에 적는다). 예외: `src/trader/kernel/web/app.py` 의 SPA 폴백·정적 서빙 버그가 있을 때만.
- 인증 3등급: 조회 토큰 없음, 쓰기(`POST/PATCH/DELETE`)는 `Authorization: Bearer <WEB_TOKEN>`(localStorage 키 `trader.webToken`), 키 입력·토큰 받기는 직접 로컬만(401/403 이면 "이 PC 에서만" 안내).
- 실전 쓰기 동작(실전 계좌 모드 변경·실전 승인·실전 auto 계좌가 있을 때의 전역 재개·실전 계좌가 포함되는 trading kind 수동 실행)은 **확인 대화상자에 계좌 id 재입력** → 요청 본문 `confirm: <계좌 id>`. 모의는 확인 대화상자만(본문 `confirm` 없음). 실전 계좌 `mode: "auto"` PATCH 의 재입력이 곧 LIVE 확인이다.
- 실시간 값은 표시 전용. 서버 `next_poll_ms` 를 따르고 주기를 하드코딩하지 않는다. 보이지 않는 탭(`document.hidden`)은 시세 폴링을 멈춘다. SSE 는 **리더 탭 하나만** 열고 `BroadcastChannel("trader-events")` 로 중계, 끊기면 30초 폴링, `visibilitychange` 복귀 시 재연결.
- 시각: 전부 KST, 미국 장 관련은 괄호 ET 병기. 서버 시각은 `X-Server-Time` 헤더·SSE ping 으로 받아 오프셋 보정, ±1초 넘게 틀어지면 상태 띠에 「시계 어긋남」.
- 금액: 원화 정수 천 단위, 달러 소수 둘째 자리, 파생은 포인트와 원화 나란히. 숫자·칩·짧은 글 열은 줄바꿈 금지, 단위는 머리글.
- 표 규칙: 본문 전체 폭, `table-layout: fixed` + 열마다 폭, 긴 글 열은 표당 하나(말줄임, 전문은 툴팁/행 펼침), 칩 넘치면 「+N」, 마스터·상세는 표 아래 펼침. 1024px 미만은 행 카드(1줄 메타 · 1줄 제목 말줄임 · 1줄 칩), 1024~1279px 는 왼쪽 메뉴 56px 아이콘 접기, 그래도 좁으면 첫 열 고정 + 가로 스크롤(열 숨김 금지).
- 레이아웃: PC(≥1024px) 왼쪽 2단 메뉴(화면 5개 + 하위 목차 한 줄씩, 현재 항목 표시, 본문에 같은 탭 중복 금지), 휴대폰 하단 탭 5개. 상세 화면은 하위 목차 위 「‹ 돌아가기」 한 줄. 상단 띠: 상태 점(정상/주의/장애) + 사유 + 「N초 전 갱신」 + 사용률 칩 2개(5시간·7일, 휴대폰은 5시간 하나; 70% 미만 초록·90% 미만 노랑·그 밖 빨강, 글귀 「사용률 · 리셋까지 남은 시간」) + 시계(KST 시:분:초 + 장 세션).
- 다크 모드: OS 설정 따름 + 토글(localStorage 키 `trader.theme`).
- 데이터가 비어 있으면 섹션을 숨긴다(fo 계좌 없음 → 파생 카드·파생 보유 숨김, `scalp` 행 없음 → 단타 절 숨김). nav 에는 "켜짐/꺼짐" 개념이 없다.
