# M5 spot 운영 경로 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 옛 `orchestrator/{monitor,resume,fills,notice,reconcile,balance,reprice}.py`·`jobs.py`·`daemon.py` 의 M5 몫을 새 저장소로 이식해, 데몬이 장중 손절·재평가 트리거·체결 동기화·잔고 스냅샷·대사·재호가를 돌리고 잡 큐로 재평가를 처리하게 한다.

**Architecture:** 커널은 **잡 큐**(`job_requests`, 레인 4개, heavy 락, 재기동 복구, 캐치업)·**게이트 공급 경로**(`Feature.gates`)·**휴장/장중 시계**(`kernel/config/market_hours.py`)·**데몬 내장 잡**(`telegram_poll`+outbox flush, 큐 틱)·**stale 세션 정리**를 얻고, 기능 이름은 여전히 모른다. `features/spot` 은 monitor·resume·fills·reconcile·balance·reprice·notice 모듈과 JobSpec·QueueKind·`RESUME` SessionKind 를 선언한다. 계좌·브로커·시세는 M4 와 같이 `ports["accounts"]`(데몬은 `DaemonDeps.ports`)로 받고, 모든 주문·취소는 `kernel/execution/core` 를 지난다(취소는 `core.cancel` 신설). 킬스위치·헤지·cash_park·메모리·섹터 분류·fo 분기·공시/뉴스 트리거 생산은 범위 밖(M6·M7·M8·M10)이고 README 「알려진 차이」에 적는다.

**Tech Stack:** Python 3.12, pydantic v2, SQLite(WAL), APScheduler(기존 daemon), typer, pytest. 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-11-02-kis-trading-agent-replatform-design.md` §2.1(features/spot Lane·OrderIntent·LaneContext), §2.3(jobs·hooks·queue_kinds·gates), §2.4(원장: fills dedupe 유니크·triggers·job_requests), §3 M5 행. 인벤토리(세션 산출물, 저장소 밖): 옛 모듈·테스트 명단은 각 Task 의 「옛 출처」에 옮겨 적었다.
