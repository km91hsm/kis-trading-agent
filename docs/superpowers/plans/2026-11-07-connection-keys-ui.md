# 연결 키 설정 가독성 개선

- 연결 키는 기본 접힘, 설정 상태 요약과 열기·숨기기 버튼을 제공한다.
- 기존 디자인 토큰과 Pretendard를 유지한다. 한글 이름·보조 환경변수명 / 상태 / 새 값 입력의 3열을 용도·계좌별 fieldset으로 묶고 작은 화면에서는 세로 배치한다.
- 숨기면 미저장 입력을 비운다. 빈칸은 서버에 보내지 않고 기존 키는 유지한다. 변경할 키 이름만 확인 후 저장한다.
- 성공 시 입력을 비우고 접으며 결과 안내와 포커스를 남긴다. 실패 시 입력과 오류를 유지한다.
- 합성 데이터로 저장·실패·키보드·라이트/다크·320~1440px를 검증한다. 실제 연결 키를 읽거나 쓰지 않는다.
- 중단된 AI 사용량 작업은 이번 변경에 포함하지 않는다. 리뷰·CI 이후 머지하고 기존 승인된 운영 반영 절차를 따른다.
