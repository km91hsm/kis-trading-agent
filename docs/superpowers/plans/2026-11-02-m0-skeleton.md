# M0 — 새 저장소 뼈대(커널·레지스트리·CI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공개 저장소 `kis-trading-agent` 를 만들고, 기능을 하나도 담지 않은 채로 `uv run trader init|selfcheck|daemon|web` 이 돌고 CI(ubuntu+windows) 가 녹색인 커널 뼈대 + 기능 레지스트리 + 계약 테스트를 세운다.

**Architecture:** `src/trader/kernel/`(기능을 모르는 층: platform·config·ledger·registry·daemon·web·cli)과 비어 있는 `src/trader/features/` 두 층. 기능은 `features/<x>/feature.py` 의 `FEATURE = Feature(...)` 하나로 등록하고, 커널은 `registry.discover()` 가 모은 선언(설정 섹션·마이그레이션·잡·라우터·SSE 키…)을 **데이터로 순회**한다. 옛 저장소(`OLD=../trading-agent`)의 해당 모듈·테스트를 가져오되 기능 의존을 끊고, 옛 if 체인은 옮기지 않는다.

**Tech Stack:** Python 3.12 · uv · pydantic v2 · typer · FastAPI/uvicorn · SQLite(WAL) · APScheduler 3 · pytest/respx/ruff · React + Vite + TypeScript(vitest) · GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-02-kis-trading-agent-replatform-design.md` (§2.1 패키지 구조, §2.3 레지스트리 계약, §2.4 원장 v1, §2.7 위생·CI, §2.7-1 import 규칙).

## Global Constraints

- Python `>=3.12`, 패키지 관리 `uv`, 패키지명·CLI 명령 `trader`, 버전 `0.2.0`.
- 경로는 전부 `pathlib`, 하드코딩 절대경로 금지, 루트는 `kernel/platform/paths` 로만(`TRADER_HOME` 은 `resolve()`, 없으면 cwd 에서 위로 `pyproject.toml` 탐색). OS 분기는 `kernel/platform/` 만.
- 파일명에 `:` 금지. 저장 시각은 UTC ISO8601, 표시만 KST. 타임존은 `zoneinfo`+`tzdata`, `KST` 는 `kernel.config.KST` 하나.
- subprocess 는 `shell=False, encoding="utf-8", errors="replace"`. 콘솔 UTF-8 강제. 셸 스크립트(.sh/.bat/.ps1) 금지.
- SQLite 는 WAL, 쓰기 타임아웃 30초, 마이그레이션은 버전 오름차순·추가만. 금액은 `Decimal`(TEXT).
- pydantic 모델은 `extra="forbid"`. 사용자 대면 문구·로그·docstring 은 한국어. 로거 이름 `trader.<계층>`.
- **import 규칙(스펙 §2.7-1)**: `kernel` 은 `features` 를 import 하지 않는다(`registry.discover` 의 동적 import 만 예외). 기능은 다른 기능의 `api.py` 만 import 한다. 레인(spot·fo·scalp)은 어떤 기능도 import 하지 않는다.
- 공개 저장소: `config/`·`secrets/`·`state/`·`dist/`·`build/`·`web/dist/` 는 `.gitignore`. `templates/config/*.yaml` 만 커밋(자리표시자 `00000000`, 개인 이메일 금지). 테스트 fixture 는 합성 데이터만.
- TDD: 실패 테스트 먼저. 테스트는 `tmp_path` 만 쓰고 네트워크는 `respx` 로 막는다. 태스크마다 커밋. 커밋 트레일러 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 매 태스크 끝: `uv run ruff check src tests` 경고 0, `uv run pytest -q` 전부 통과.

## Review Focus

1. `TRADER_HOME` 이 상대 경로이거나 미설정 + cwd 에 `pyproject.toml` 이 없을 때 — 절대 경로로 resolve 하거나 `ProjectRootNotFound`(한국어 메시지)를 내야 한다(Task 2 테스트).
2. 템플릿·설정 yaml 에 등록되지 않은 키가 있을 때 — `ConfigError` 메시지에 **파일명과 키 이름**이 있어야 사용자가 고칠 수 있다(Task 3 테스트).
3. 두 기능이 같은 마이그레이션 버전을 선언했을 때 — 조용히 하나를 덮지 말고 기동 자체를 거부해야 한다(Task 5 테스트).
4. 비루프백 `Host` 헤더로 들어온 요청 — 조회 API 라도 거부해야 한다(Task 7 테스트).
5. Windows 에서 다른 프로세스가 로그 파일을 쥐고 있어 회전이 `PermissionError` 일 때 — 로그를 멈추지 말고 같은 파일에 계속 써야 한다(Task 2 테스트, CI windows 매트릭스가 실제 OS 에서 검증).
