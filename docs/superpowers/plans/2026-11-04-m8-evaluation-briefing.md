## Ruling(플랜 단계 결정 — 실행 중 틀린 것이 드러나면 장부에 적고 되돌린다)

- **A1** RL 사이저는 `features/evaluation/rl/`(evaluation 이 `rl_shadow`·`rl_train` 잡·큐·CLI 소유). ml 은 `api` 에 `walkforward_folds`·`check_no_leak`·`make_labels`·`registry_save/load/list_models/latest/promote/demote`·`CalibrationCfg`·`RlSizerCfg` 를 내놓는다. 옛 `_ml_train_body` 가 RL 학습을 연쇄하던 것은 **evaluation 의 독립 cron `rl_train`(토 10:30 KST)** 로 바꾼다 — 비용: 설정 키 1개, 옛 `test_ml_train_job_trains_sizer_even_when_not_enabled` 는 `test_rl_train_job_trains_sizer_even_when_not_enabled` 로 옮긴다.
- **A2** 레인 접점은 `ports["evaluation"]`(커널 `EvaluationPort` Protocol) 하나: `memory_context`·`calibration_injected`·`calibration_report`·`record_decision`·`update_breaker`·`rl_sizer`·`rl_propose`·`rl_record`.
- **A3** `memory_entries` 에서 `realized_return`·`alpha_vs_benchmark` 열을 폐기한다(스펙 §2.4). `fill_outcome` 승격 기준은 `|direction_score|`; `backtest` 의 `realized_return` 은 `direction_score`, `alpha` 는 종가표가 있을 때만 `window_return` 벤치마크로 계산(없으면 None); `calibration.signal_hits` 는 `price_return` 만 쓴다. 옛 v23/v30 마이그레이션 테스트 3건은 이식하지 않는다(새 스키마는 처음부터 최종형).
- **A4** `shadow_portfolios.def_version NOT NULL` 이라 옛 `test_legacy_llm_rows_are_excluded_from_revised_selection_stats` 의 NULL 절반은 뺀다(`record` 가 `DEF_VERSION` 을 쓰는 단언만 남김).
- **A5** `round_trip_bp` 를 커널 `kernel/execution/costs.py` 로 승격한다(`ROUND_TRIP_BP = {"KR": 30, "US": 50}`; 모르는 시장은 US). spot `costs.round_trip_bp` 와 scan `backtest.ROUND_TRIP_BP` 는 커널 것을 재노출(M7 Ruling P1 의 중복 해소).
- **A6** `MonitorContext.close_table` 주입(M5 Ruling 14): `MlPort.close_table(market, since, until) -> Mapping[str, Mapping[date, float|None]]` 을 더하고 spot 데몬·CLI 가 `ports["ml"]` 가 있으면 넣는다.
- **A7** 일일 스냅샷은 `features_snapshot` cron(06:30)을 유지하고, reflect 는 스냅샷을 **다시** 돈다(KR 당일 종가 + 열린 창 종목 `extra_targets`). 멱등이라 중복 무해.
- **A8** reflect 잡의 보존 정리(`retention.prune`)는 M12(ops)로 — 반환 dict 에 `retention` 키 없음. `fills` 선동기화(옛 `_daily_report_body` 의 `_fills_body`)는 레인 호출이라 하지 않는다 — US 일일 리포트(16:20 ET)는 07:10 KST `fills_sync` 전이라 `realized_5d` 가 하루 늦을 수 있다(README).
- **A9** 브리핑 시각은 `schedule.yaml briefing: "07:20"`(옛 `settings.briefing.time`), 나머지(`enabled`·`daily_cap`·`timeout_s`)는 `settings.yaml briefing:`. 잡은 `per_market=False`, 본문이 KR 휴장일·일시정지를 직접 본다(옛 `market_job(deps,"KR",…)` 과 같은 효과).

- **A11** `readiness.check` 는 interval 잡 종류를 하드코딩하지 않고 `interval_kinds_of(features)` 로 받는다(옛 `INTERVAL_KIND_SQL` 대체; 옛 테스트의 `kr_monitor`·`fills_sync_1`·`telegram_poll` 제외 단언은 `interval_kinds={"kr_monitor","us_monitor","fills_sync","telegram_poll"}` 를 넘겨 유지). 보정 설정은 `calibration: CalibrationCfg|None` 인자로 받는다.
- **A12** `memory_context` 의 `latest_row` 는 `asof=당일` 로 통일한다(옛은 asof 없이 최신 행 — 기록 벡터와 질의 벡터의 피처 날짜가 달라지는 결함을 고침). `ReflectParams.market` 이 주어지면 그 시장만 복기한다(옛은 무시).

- **A14** `metrics.decision_distribution`·`convergence_rate` 는 evaluation `metrics.py`(`kernel.session.debate.CONVERGENCE_GAP` 사용). 옛 `metrics.pending_approvals`·`account_stance`·`stance_by_market` 는 M11 웹에서.
