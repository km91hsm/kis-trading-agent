# WEB UI 운영 가시성 보완

사용자 승인: WEB UI 검토의 모든 기능·디자인 항목을 보완한다. 기존 React/FastAPI/SQLite 구조와 웹 디자인 체계를 유지한다.

## 요구사항
1. SaveTicker healthy/collecting은 수집 중으로 표시하고 휴장·미수집·지연·실패를 구분한다.
2. 데이터 수집 절에 원천/스트림별 최근 시도·성공·값 변화·0건·오류·복구 상태를 표시한다. 요청 성공과 값 변화는 다른 개념이며 임의 분모의 19/20을 만들지 않는다.
3. 결정 상세에 세션 당시 수집 입력과 모델에 전달된 입력의 구분, 건수·누락·시각·원문 링크를 제공한다. 전달이 실제 활용을 보장한다는 문구 금지. 과거 정확한 전달 기록이 없으면 명확히 미기록/재구성으로 표시한다.
4. S&P500·나스닥 종합·미국채10년·WTI·달러지수의 최신 저장 관측값·등락·출처·시각·실제/대체 지표를 표시한다. 미제공 값은 계산/추정하지 않는다. UI GET으로 외부 시세를 새로 수집하지 않는다.
5. 토론의 동일 쟁점에 주장·상대 반론·재답변·합의 여부와 확신 변화를 연결하고 근거를 확인할 수 있게 한다. 모델명이 미기록이면 역할로 공급자를 추정하지 않는다.
6. 거래대금 순위 필터·5분 증가율 정렬·계산 불가 사유·차트 이동을 제공한다. URL에 선택을 보존한다. 수집 범위 안의 정렬이며 전체 시장 순위가 아니다.
7. 오늘 화면 상단에 시장 상태·새 분석 제한·수집 상태·Claude/Codex 참여 상태를 요약한다. 프로그램 정상과 거래/분석 가능 여부는 별도다. 과거 날짜에는 현재 상태임을 명시한다.
8. 반복 제목/긴 설명을 정리하고 Codex 설정 바로가기·리스크 실제 설정값을 제공한다. 본문 바로가기, 키보드 포커스, 모바일/다크모드 지원.

## 제약
- 주문/계좌모드/리스크 실행 규칙을 변경하지 않는다. 실제 주문, 실제 모델 호출, 새 유료 계약 없음.
- secrets/를 읽지 않는다. config/accounts.yaml 내용 출력 금지. 운영 state 직접 변경 금지.
- 기존 web/DESIGN.md가 스타일 정본. Pretendard, 중립색, 상승 적·하락 청, 라이트/다크, 14px 본문 유지. 추가 의존성 없음.
- UI는 문장·표 중심. 외부 원문은 합성 fixture로만 테스트하고 공개 저장소에 실제 자료를 커밋하지 않는다.
- 전체 pytest는 한 번에 하나. 독립 작업 대상 테스트도 공유 잠금으로 순차 실행.

## 시각 구성
오늘: 현재 운영 요약(시장/분석/수집/모델) → 승인 → 오늘 성과 → 파이프라인/결정.
데이터: 매크로 5항목 요약 → 거래대금 필터·표 → 종목 차트. 출처/제약은 상세 접기.
결정: 판단 요약 → 입력 내역 → 쟁점별 양측 비교 → 원래 상세 추적.
시스템: 데이터 수집 요약 → 항목별 상태 표. 관리: 설정에 바로 도달하는 링크 및 의미 있는 리스크 값.
