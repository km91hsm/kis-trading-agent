# 단타 계좌별 켜기·끄기 + 일시정지·운영 점검 표기 (설계)

날짜: 2026-11-09 · 크기: 중간

## 의도
1. 단타(scalp)는 지금 설정 파일(`scalp.enabled`)로만 켜고 끄며 **모의 계좌 전용**이다(`features/scalp/engine.py:222 skip_accounts`, A8). 사용자는 Codex 토론처럼 웹 버튼으로 켜고 끄되, **모의·실전 계좌를 각각** 제어하고 싶다.
2. 시스템 › 헬스의 「일시정지」와 「정상」이 무엇을 뜻하는지 구분이 안 된다 — 「정상」은 운영 점검 결과, 「일시정지」는 자동매매 전체 일시정지 스위치(control `paused`)다.
3. 계좌 모드가 「자동」인데 대시보드는 「일시정지」로 보여 헷갈린다 — 둘은 다른 설정(계좌별 모드 vs 전역 비상 정지)이다. 실제로 2026-11-08 12:33 KST 에 ▲ 메뉴(트레이)에서 일시정지가 켜졌다(앱 교체 중 「종료」 대신 누른 것으로 보임).

## 사용자 결정
- 실전 계좌 단타 허용. 켤 때 **계좌 id 를 직접 입력해 확인**. 실전 계좌 단타는 그 계좌가 **「자동」 모드이고 LIVE 확인이 된 상태에서만** 돈다. **상한·조건은 모의와 같다.**
- 2·3 은 화면에 어느 정도 표기가 있어야 한다.

## 설계

### 1. 단타 계좌별 스위치
- 저장: control 플래그 `scalp_enabled:<계좌id>` (bool). 없으면 기본값: 모의 계좌 = yaml `scalp.enabled`, 실전 계좌 = **꺼짐**(yaml 값과 무관 — 실전은 화면에서 명시적으로 켠 경우만). 실전 켜기 기록에는 `{enabled: true, confirm: <id>, at, actor}` 를 함께 남긴다(control_log 도).
- 실효 판정 `scalp.account_enabled(conn, settings, account) -> (bool, 사유)`:
  - 모의: 스위치 켜짐.
  - 실전: 스위치 켜짐 ∧ 실효 계좌 모드(`accounts.effective_mode`) 가 `auto`(LIVE 확인 포함 — 확인 없으면 effective 가 off) ∧ 전역 일시정지 아님(기존 주문 경로가 이미 막음).
  - 단타 잡(`scalp/jobs.py`)·엔진(`engine.py`)은 전역 `scalp.enabled` 대신 「켜진 계좌가 하나라도 있으면 돈다」, 주문 대상은 `skip_accounts` = 실효 판정이 거짓인 계좌 + 그 시장이 아닌 계좌. 모의 전용 문구(`status.py`·CLI 도움말·README·CLAUDE.md 명령 표)를 「계좌별(실전은 확인·자동·LIVE 필요)」로.
  - 기능 경계: scalp 는 accounts 의 공개면(`ports["accounts"]` 또는 accounts `api.py`)으로만 모드를 읽는다(직접 import 금지).
- 웹 API: `GET /settings/scalp` → 계좌마다 `{id, env, enabled, source(control|yaml|default), effective, reason}` + 판정자(`scalp.judge`) 상태. `PATCH /settings/scalp/{account_id} {enabled: bool|null, confirm?: str}` — WRITE, 실전 계좌를 켤 때는 `confirm == 계좌 id` 가 아니면 400(웹 불변식 「실전 쓰기는 confirm == 계좌 id」와 같은 규칙), null = 기본값으로.
- 웹 화면: 시스템 › 관리 › 설정에 「단타」 카드(Codex 토론 카드 옆) — 계좌 표: 계좌(코드)·환경(모의/실전)·스위치·실효 상태(「동작」/「꺼짐」/「실전: 계좌 모드가 자동이 아니라 멈춤」 등). 실전 켜기는 Confirm 대화상자에 계좌 id 입력.

### 2. 헬스 표기
- 시스템 › 상태 › 헬스 머리를 두 줄로: 「운영 점검: 정상 — 데몬·잡·주문·수집 등 N개 영역 문제없음」(또는 주의/위험 + 영역 수), 「자동매매: 동작 중」 또는 「자동매매: 전체 일시정지 중 — 새 주문·승인을 내지 않음 · <시각> <경로(▲메뉴/웹/텔레그램)>」 + [재개] 링크(계좌 화면의 기존 일시정지 버튼으로).

### 3. 대시보드·계좌 표기와 ▲ 메뉴
- 오늘(대시보드) 레인 카드: 「일시정지」 배지에 툴팁·한 줄 설명 「전체 자동매매 일시정지 — 계좌 모드와 별개」, 그리고 화면 맨 위에 전역 일시정지 띠(켜졌을 때만): 「자동매매 전체 일시정지 중 · <시각> <경로> — 계좌 모드(자동/승인)는 그대로, 새 주문만 멈춤 [재개]」.
- 계좌 목록·계좌 상세: 모드 옆에 「(전체 일시정지로 주문 멈춤)」 보조 표기(일시정지일 때만).
- 일시정지 시각·경로: `control_log` 의 최근 `paused` 변경(channel·at)을 `/system/status`(또는 `/accounts/overview`) 응답에 `paused_at`·`paused_by` 로 싣는다.
- ▲ 메뉴: 「일시정지」를 누르면 OS 확인 대화상자(「자동매매를 전체 일시정지할까요? 새 주문·승인이 멈춥니다」) — macOS·Windows 트레이 구현(`kernel/platform/tray.py`)이 지원하는 방식으로. 메뉴 순서에서 「일시정지」와 「종료」 사이에 구분선.

## 비목표
- 단타 판정자(`scalp.judge`)·상한의 계좌별 설정(전역 그대로). 실전 전용 상한 없음(사용자 결정).
- 파생(fo)·현물 레인의 동작 변경 없음.
