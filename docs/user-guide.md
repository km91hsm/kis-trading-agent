# Trader 사용자 설명서

한국투자증권(KIS) Open API 로 국내·미국 주식을 자동으로 분석하고 매매하는 개인용 데스크톱 앱입니다.
이 문서는 **제품 개요 → 설치 → 처음 설정 → 사용법** 순서로 설명합니다. 설치 화면별 세부 절차·업데이트·문제 해결은
[설치 안내](bundle-usage.md)에 있습니다.

---

## 1. 제품 개요

### 무엇을 하나

- **매일 아침 시장을 읽고**(국면 판정·테마 감지·뉴스·공시·거시 지표), 살펴볼 종목을 고릅니다.
- **종목마다 AI 분석 세션**을 돌려(애널리스트 4명 + 강세·약세 토론 + 트레이더) 매수·매도·보유 결정을 냅니다.
- **파이썬 리스크 게이트**가 계좌별 한도·비중·손절선·일시정지·킬스위치를 검사해 통과한 것만 주문하거나 승인 요청을 보냅니다.
- **장중에는 보유 종목을 감시**해 손절선 도달 시 즉시 매도하고, 트리거가 걸리면 다시 평가합니다.
- **장 마감 뒤**에는 체결 동기화·대사·일일 리포트·복기(결정이 맞았는지 채점하고 교훈을 메모리에 남김)를 합니다.
- **주말**에는 퀀트 모델(ML)과 포지션 크기 조절(RL)을 다시 학습합니다.

### 핵심 원칙 — AI 는 제안만, 돈은 코드가 지킨다

| 원칙 | 내용 |
|---|---|
| AI 는 도구만 쓴다 | AI(Claude)는 정해진 `trader tool` 명령으로 자료를 읽고 의견을 낼 뿐, 주문·원장·파일을 직접 건드리지 않습니다. |
| 주문은 한 길로만 | 모든 주문은 파이썬 실행 코어(게이트 → 중복 방지 → 승인 → 기록)를 지납니다. |
| 계좌 모드 | 계좌마다 `off`(주문 안 함) · `approve`(텔레그램·웹 승인 후 주문) · `auto`(게이트 통과 시 자동 주문). 실전 계좌의 `auto` 는 별도 LIVE 확인이 있어야 켜집니다. |
| 언제든 멈춤 | 전역 **일시정지**(웹·트레이·텔레그램 `/pause`)와 **킬스위치**가 켜지면 새 주문이 모두 멈춥니다. |
| 미래 정보 금지 | 판단·학습·백테스트는 그 시점에 알 수 있던 자료만 씁니다. |

### 구성 요소

| 구성 | 하는 일 |
|---|---|
| **Trader 앱** (메뉴바/작업표시줄 ▲) | 스케줄 데몬 + 웹 UI 를 한 프로세스로 돌립니다. 로그인 시 자동 시작할 수 있습니다. |
| **웹 UI** `http://127.0.0.1:8787` | 오늘 현황·결정·승인·계좌·성과·데이터·시스템 상태를 보는 화면입니다. |
| **텔레그램 봇** | 알림 수신과 승인·일시정지·모드 변경을 폰에서 합니다. |
| **Claude Code CLI** | AI 분석 세션을 돌리는 엔진입니다(구독 로그인 필요, 앱에 포함되지 않음). |
| **세이브티커 Chrome 확장**(선택) | 로그인한 Chrome 화면에서 뉴스·리포트·순위·캘린더를 모아 분석 자료로 씁니다. |

## 2. 설치

[GitHub Releases](https://github.com/km91hsm/kis-trading-agent/releases) 에서 파일 하나를 받습니다.

| 운영체제 | 파일 | 설치 |
|---|---|---|
| macOS (Apple 실리콘) | `trader-<버전>-macos-arm64.dmg` | 열어서 Trader 를 Applications 로 끌어다 놓기 |
| macOS (Intel) | `trader-<버전>-macos-x86_64.dmg` | 같음 |
| Windows 64비트 | `trader-<버전>-windows-x86_64-setup.exe` | 실행(관리자 권한 불필요) |

- 코드 서명이 없어 첫 실행 때 macOS 는 "확인되지 않은 개발자"(응용 프로그램 폴더에서 **우클릭 → 열기**), Windows 는
  SmartScreen(**추가 정보 → 실행**) 경고가 뜹니다.
- 앱과 데이터는 분리돼 있습니다. 앱을 바꾸거나 지워도 데이터 폴더는 남습니다.

| | macOS | Windows |
|---|---|---|
| 앱 | `/Applications/Trader.app` | `%LOCALAPPDATA%\Programs\Trader\` |
| 데이터 폴더 | `~/Library/Application Support/Trader` | `%LOCALAPPDATA%\Trader` |
| 터미널 명령 | `/Applications/Trader.app/Contents/MacOS/trader` | `%LOCALAPPDATA%\Programs\Trader\trader.exe` |

자세한 화면별 절차는 [설치 안내 2절](bundle-usage.md#2-설치).

## 3. 처음 설정

1. **Claude Code 준비**: https://claude.ai/code 안내대로 `claude` 를 설치하고 한 번 로그인합니다(`claude --version` 확인).
2. **앱 실행**: 처음 실행하면 데이터 폴더에 `config/`·`secrets/`·`state/`·`docs/` 가 생기고 웹 UI 가 열립니다.
3. **키 넣기**: ▲ 메뉴 **데이터 폴더 열기** → `secrets/.env` 에 `secrets/.env.example` 의 이름대로 줄을 덧붙입니다
   (KIS 모의·실전 앱키, DART, FRED, 네이버 API, 텔레그램 봇 토큰·chat_id). 이미 들어 있는 `WEB_TOKEN` 줄은 그대로 둡니다.
4. **계좌**: `config/accounts.yaml` 의 `cano` 자리(`00000000`)를 본인 계좌번호로 바꿉니다. 처음에는 모의 계좌 `auto`,
   실전 계좌 `off` 로 시작하길 권합니다.
5. **SEC 연락처**: `config/sources.yaml` 의 `edgar.user_agent` 에 `<이름> <이메일>` 을 넣습니다(미국 공시 수집 요구 사항).
6. **점검**: 터미널에서
   ```
   trader accounts ping      # KIS 시세·계좌 연결
   trader selfcheck          # 설치 점검(JSON 1줄, ok:true 면 정상)
   trader notify-test        # 텔레그램 시험 메시지
   ```
7. **자동 시작**: ▲ 메뉴 **로그인 시 자동 시작**을 체크합니다(또는 `trader install`, 데몬 밖 5분 감시는 `trader install --watchdog`).
8. **웹 쓰기 권한**: 웹 UI 의 시스템 화면에서 **이 PC 에서 받기**를 눌러 쓰기 토큰을 받습니다. 토큰이 없으면 조회만 됩니다.

## 4. 사용법

### 4-1. 메뉴바/작업표시줄 ▲

| 메뉴 | 동작 |
|---|---|
| 웹 UI 열기 | 브라우저로 `http://127.0.0.1:8787` |
| 일시정지 / 재개 | 새 주문 전체를 멈추거나 다시 허용 |
| 로그 폴더 열기 · 데이터 폴더 열기 | `state/logs` · 데이터 폴더를 Finder/탐색기로 |
| 로그인 시 자동 시작 | 체크로 켜고 끔 |
| 종료 | 실행 중인 분석 세션이 끝나길 기다린 뒤 종료 |

### 4-2. 웹 UI

| 메뉴 | 볼 수 있는 것 |
|---|---|
| **오늘** (현황·기록·승인) | 아침 파이프라인 진행, 결정·리스크 게이트 결과, 주문·체결, 승인 대기, 다음 할 일, 알림. 현물·단타·파생 탭 |
| **계좌·보유** | 계좌별·통합 보유와 평가, 파생 계좌 |
| **성과** | 성과·계좌 비교, 복기(결정 채점과 교훈), 보정, 섀도 기준선, RL, 파생 성적표 |
| **데이터** | 시세·차트, 뉴스·공시, 테마·감시목록, 지표·모델 |
| **시스템** | 상태(운영 점검·데몬·세이브티커), 잡(실행 기록·수동 실행), 기능, 연결 키 설정 |

- 승인·일시정지·모드 변경·작업 실행 같은 **쓰기**는 쓰기 토큰이 있는 브라우저에서만 됩니다.
  실전 계좌에 대한 쓰기는 계좌 id 를 한 번 더 입력해 확인합니다.
- 폰에서 보려면 같은 네트워크(또는 tailnet)에서 `http://<PC 주소>:8787` 로 접속하고 토큰을 붙여 넣습니다.
- **AI 사용량**(시스템 › 상태 › 사용량): Claude·Codex 의 5시간·7일 구독 사용률과 오늘 쓴 횟수를 봅니다.
  - Claude **사용량 조절**: 켜 두면 사용률이 80% 이상일 때 보유 재평가만, 95% 이상이면 새 세션을 멈춥니다.
    **하루 세션 제한**은 「제한 변경」으로 바꾸고(매일 적용), 「기본값으로」는 설정 파일 값(`llm.daily_session_cap`)으로 되돌립니다.
  - Codex **사용량 조절**: 켜 두면 새 분석을 시작할 때 Codex 사용률이 95% 이상이거나 **하루 호출 제한**에 닿았으면
    그 분석은 Claude 가 강세·약세를 모두 맡습니다(여유가 생기면 다음 분석부터 다시 Codex). 꺼 두면 사용률과 관계없이
    하루 제한까지 Codex 를 씁니다. 하루 호출 제한도 「제한 변경」으로 바꿉니다.

### 4-3. 텔레그램 명령

| 명령 | 동작 |
|---|---|
| `/status` | 데몬·계좌·운영 점검 요약 |
| `/daily` | 오늘 NAV·주문 일일 리포트 |
| `/approve <id> [실전]` · `/reject <id>` | 승인 요청 실행·거부 |
| `/pause` · `/resume` | 전역 일시정지·재개 |
| `/mode <계좌> <auto\|approve\|off>` | 계좌 모드 변경 |
| `/watch add\|remove\|list <종목>` | 관심종목 관리 |
| `/run <작업>` | 데몬 큐에 작업 요청 |
| `/fo` | 파생 포지션(파생 레인을 켠 경우) |

### 4-4. 자주 쓰는 터미널 명령

macOS 는 한 번 `alias trader=/Applications/Trader.app/Contents/MacOS/trader` 를 등록해 두면 편합니다.

| 명령 | 용도 |
|---|---|
| `trader status` | `state/STATUS.md` 생성(운영 점검·데몬·마지막 실행·오늘 LLM 호출) |
| `trader accounts show` · `pause` · `resume` | 계좌 목록·일시정지 |
| `trader spot approvals list` | 승인 대기 목록 |
| `trader jobs kinds` · `trader jobs run <작업>` | 실행 가능한 작업 목록 · 데몬 큐에 요청 |
| `trader regime show` | 현재 시장 국면 |
| `trader scan theme show` | 오늘의 테마 점수 |
| `trader evaluation readiness` | 실전 전환 준비도 |
| `trader evaluation backtest --since YYYY-MM-DD` | 백테스트 |
| `trader ml models` | 퀀트 모델 목록 |
| `trader saveticker extension status` | 세이브티커 확장 연결 상태 |
| `trader saveticker login set` | 세이브티커 계속 복구용 이메일·비밀번호 저장(`status`·`clear`) |

### 4-5. 세이브티커 수집(선택)

1. 앱을 실행하면 웹 화면 맨 위에 **「세이브티커 뉴스 수집을 쓰시겠어요?」** 가 뜹니다 → **설치하기**
   (나중에 하려면 시스템 › 기능 › 데이터 수집의 **설치/갱신**). 확장 복사와 Chrome 연결 등록이 바로 끝납니다.
   이 PC 에서 직접 연 화면에서만 됩니다. 터미널을 쓴다면 `trader saveticker extension install` 도 같습니다.
2. 화면 안내대로 Chrome `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램을 로드합니다** →
   **경로 복사** 한 폴더 선택(macOS 는 선택 창에서 `Cmd+Shift+G` 로 붙여 넣기). 이 단계만은 Chrome 이 막아 직접 해야 합니다.
3. Chrome 에서 세이브티커에 직접 로그인 → 확장 팝업 **수집 시작**
4. 보안 확인이 뜨면 전용 탭에서 직접 통과한 뒤 **직접 확인 후 재개**. 확장은 보안 확인·CAPTCHA 를 우회하지 않습니다.
5. (선택) 멈추지 않게 하려면: 시스템 › 관리 › **연결 키** 의 「세이브티커」 묶음에 이메일·비밀번호를 저장하고
   (비밀번호에 공백이 있거나 따옴표·`#` 로 시작하면 터미널 `trader saveticker login set`), 수집 중지 상태의 팝업에서
   **재확인 안내 시 1회 자동 새로고침** 과 **재확인 시 계속 복구** 를 켭니다. 재확인·로그아웃이 생겨도 수집을 끄지 않고
   1→2→4→8→15분(이후 15분마다) 간격으로 새로고침하며, 로그아웃이면 자동으로 이메일 로그인합니다. 전용 탭이 사라졌거나
   로그인 정보가 없거나 비밀번호가 3번 연속 틀리면 그때만 멈춥니다.

Chrome 이 켜져 있고 컴퓨터가 깨어 있어야 수집합니다. 옵션은 [설치 안내 6절](bundle-usage.md#6-세이브티커-수집선택).

## 5. 안전하게 쓰기

- 처음 몇 주는 **모의 계좌만 `auto`**, 실전은 `off` 또는 `approve` 로 두고 웹 **성과**·**복기**로 결정 품질을 확인하세요.
- `trader evaluation readiness` 로 실전 전환 준비도(모의 운용 기간·잡 실행 상태 등 점검 항목)를 확인합니다.
- 장중에 앱을 끄면 감시·손절도 멈춥니다. 자동 시작과 `--watchdog` 감시(데몬이 죽으면 텔레그램 알림)를 켜 두세요.
- Claude 구독 7일 사용률이 80% 를 넘으면 새 종목 분석을 건너뛰고 보유 재평가만 합니다(운영 점검에 표시).
- 데이터 폴더 전체가 백업 대상입니다. 원장은 매일 17:10 `state/backups/` 에 자동 백업됩니다.

## 6. 업데이트 · 백업 · 제거

- **업데이트**: 확장 수집 중지 → ▲ 종료 → 새 dmg 로 Trader 를 대치(Windows 는 새 setup.exe 실행) → 앱 실행.
  "확장을 새로고침하세요" 알림이 오면 `chrome://extensions` 에서 ↻.
- **백업**: 데이터 폴더를 통째로 복사합니다.
- **제거**: ▲ 「로그인 시 자동 시작」 해제 → `trader saveticker extension uninstall`(썼다면) → 종료 → 앱 삭제
  (Windows 는 설정의 앱 제거). 데이터 폴더는 남으니 필요 없으면 직접 지웁니다.

자세한 절차·옛 버전에서 넘어오기·문제 해결은 [설치 안내](bundle-usage.md) 7~10절.
