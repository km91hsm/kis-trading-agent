# 상세 화면과 이동 흐름 검증 기록

기준: `b58abb1e931203c10f3207d82d1f1280344b8142`, 브랜치 `feat/m12-context-friendly-web`.

## 변경 범위

- 계좌의 시장 선택과 성과 조회 조건을 URL에 유지한다. 조건 변경 중에는 이전 조건의 값을 숨긴다.
- 계좌 상세는 자산 요약·보유·위험·주문을 우선하고 큰 자산 추이는 기본 접는다. 세금·고급 분석·수동 작업도 필요할 때 펼친다.
- 파생 보유·만기·증거금·계약별 주문 진행은 해당 파생 계좌 상세에서, 파생 누적 성적표는 기본 성과에서 확인한다. 누적 집계의 별도 범위를 표시한다.
- 종목 검색·차트를 앞에 배치하고 종목·시장·확인된 거래소 정보를 뉴스/차트 이동에 전달한다.
- 자동 작업은 요청 기록이 먼저다. 실행 확인창에 대상·주문 가능성·미확인 AI 영향과 접수/실행 완료의 차이를 설명한다. POST 계약은 유지한다.
- 조회 실패에 재시도와 도움 링크를 제공한다. 지연 로딩 및 접힌 절의 바로가기는 도착 후 위치를 보정하고 사용자 입력 시 자동 이동을 멈춘다.
- Python 변경은 거래소 응답 필드와 메뉴 생성 선언뿐이다. 주문·위험 집행 규칙은 변경하지 않았다.

## 자동 검사

- 주요 동작은 실패 테스트를 먼저 실행한 뒤 구현했다. 독립 검토에서 발견한 성과 조건 보존 및 계좌 목록 오류 재시도도 RED→GREEN으로 수정했다.
- 최종 웹: `npm run typecheck`, `npx vitest run` **57파일 617개 통과**, `npm run build` 통과. 기존 큰 청크 경고는 유지된다.
- `uv run ruff check src tests`, `trader dev gen-nav --check`, `trader dev gen-sse-keys --check`, `git diff --check` 통과.
- Python 표시/메뉴 관련 focused 검사 23개와 메뉴 최종 검사 8개 통과.
- Python 전체 1차: **4238 passed, 1 skipped, 1 failed** (929.07초). 2차: **4238 passed, 1 skipped, 1 failed** (1031.52초).
- 두 실패 모두 변경하지 않은 `tests/features/saveticker/test_api_browser.py::test_production_api_recovers_after_isolated_browser_restart`의 자동 복구 45초 대기 단언이다. 확장·수집 코드 및 해당 테스트의 기준 대비 diff는 없다.
- 같은 재시작 테스트 단독 실행은 기준 main **1 passed (39.29초)**, 작업 브랜치 **1 passed (38.86초)**. 기준 main에서 해당 파일 전체도 **2 passed (43.87초)**. 단독 통과를 전체 검사 통과로 간주하지 않으며, 전체 실행의 실패 원인은 아직 확정하지 않았다. 원본 main 전체 검사와 PR CI에서 추가 비교한다.

## 독립 검토

전체 diff를 요구사항 적합성과 저장소 규칙 두 축으로 독립 검토했다. 성과 메뉴 왕복 시 조건 초기화, 계좌 목록 조회 실패 시 재시도 누락 두 P2를 수정했다. 수정 후 및 마지막 모바일 자산 추이 재배치의 증분 검토에서 추가 P1/P2가 없었다.

## 실제 브라우저 검증

실제 브로커·AI·운영 원장과 연결하지 않은 합성 미리보기에서 375·768·1024·1440px와 라이트/다크 테마를 확인했다.

- 성과의 계좌·US·90일 선택을 주 메뉴 왕복과 새로고침 후 유지.
- 계좌 US 위험 조회의 첫 오류 후 재시도 성공, 조건에 맞는 카드 표시.
- 파생 계좌별 주문 진행과 `#fo-legs`, 파생 성과 `#fo` 이동.
- 접힌 고급 분석 `#rl`, 자산 추이 `#nav-chart` 직접 이동 시 펼침/위치 보정.
- 종목/시장/거래소를 보존한 차트 진입과 검색 우선 배치.
- 375px 실행 확인창의 대상·영향 안내, 필수 확인 전 비활성 상태와 취소. 실행 POST는 하지 않았다.
- 모바일에서 큰 차트보다 보유·위험·주문을 먼저 표시.

합성 응답으로는 실제 금융 수치의 정확성을 검증하지 않았다. 설치된 운영 앱의 교체·시작·재시작, 실제 주문 및 계좌/정책 변경은 수행하지 않았다. 최종 CI/머지 상태는 해당 PR 기록을 따른다.
